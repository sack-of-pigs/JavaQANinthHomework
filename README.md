# Сервис статистики продаж: Работа с массивами и циклами в Java

Проект посвящен разработке бизнес-логики для анализа финансовых показателей предприятия. Основной фокус сделан на работу со структурами данных (одномерные массивы), алгоритмы обхода массивов в циклах, а также на обеспечение 100% тестового покрытия для всех аналитических методов сервиса.

## 🎯 Цели и задачи проекта
* **Работа с массивами**: получение практического опыта обработки массивов данных (поиск суммы, среднего, экстремумов).
* **Алгоритмическое мышление**: реализация логики поиска *последнего* месяца, соответствующего условиям максимума/минимума (учет знаков сравнения в условиях).
* **Проектирование сервисов**: создание класса с высокой степенью автономности (`StatsService`), способного обрабатывать любые корректные массивы данных.
* **Unit-тестирование**: написание изолированных автотестов на JUnit 5 для каждого метода с целью верификации расчетов на эталонном наборе данных.

---

## 📈 Бизнес-логика и аналитические функции

В рамках проекта разработан класс `StatsService` в пакете `ru.netology.stats`, содержащий 6 методов для расчета следующих показателей:

1. **Сумма всех продаж** — общий оборот компании за весь период.
2. **Средняя сумма продаж в месяц** — среднемесячное значение оборота.
3. **Месяц пика продаж** — номер *последнего* месяца, в котором осуществлены продажи на максимальную сумму.
4. **Месяц минимума продаж** — номер *последнего* месяца, в котором осуществлены продажи на минимальную сумму.
5. **Количество месяцев ниже среднего** — подсчет месяцев, где оборот уступал среднемесячному.
6. **Количество месяцев выше среднего** — подсчет месяцев, где оборот превышал среднемесячное значение.

> **Важная деталь алгоритма**: Поскольку индексация в массивах Java начинается с `0`, при расчете номеров месяцев сервис автоматически производит корректировку (`индекс + 1`) для выдачи ответа в привычном для пользователя формате (от 1 до 12).

## 🧪 Тестирование и верификация (JUnit 5)

Для верификации алгоритмов в классе `StatsServiceTest` были написаны автотесты. В качестве эталонного набора данных использовался следующий массив продаж предприятия (до 5 млрд в месяц):
`[8, 15, 13, 15, 17, 20, 19, 20, 7, 14, 14, 18]`

### Результаты прохождения тестов:
* Тест суммы продаж ➡️ **Passed**
* Тест средней суммы продаж ➡️ **Passed**
* Тест пика продаж (ожидается последний — 8-й месяц) ➡️ **Passed**
* Тест минимума продаж (ожидается 9-й месяц) ➡️ **Passed**
* Тест месяцев ниже среднего ➡️ **Passed**
* Тест месяцев выше среднего ➡️ **Passed**

Запуск всего тестового пакета и сборка проекта выполняются одной командой:
```bash
mvn clean test
```
*Сборка гарантированно завершается со статусом `BUILD SUCCESS`.*
